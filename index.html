Positions per competition

For each competition detected in this event, enter the positions in the order they are played, separated by commas — e.g. W1, W2, W3 for women and M1, M2, M3, M4 for men. The order here is the order of play. Leave empty for a single referee per tie.

Data storage

The anon key is meant for the client and is safe to expose, but it is stored locally in this browser – not in the GitHub repo. Additionally protect the tables via Supabase RLS policies (see schema).

Account & access

Users are managed in Supabase (Authentication → Users). To stop self sign-up, disable "Allow new users to sign up" under Auth → Providers → Email and add people manually.
